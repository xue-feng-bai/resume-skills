# Claude Resume OS

> 不是改简历，是重构你的求职竞争力。

一套面向 Claude Code 的求职操作系统，覆盖从简历自检、岗位匹配、深度诊断到面试备战的全链路。每个 Skill 都是独立的战术单元，组合使用则是一套完整的求职战略。

---

## 产品矩阵

### resume-polish · 自检层
**向内审视，先修内功。**

无需任何岗位信息，通过五维度扫描引擎（零错误 / 结构完整性 / 叙事质量 / 卖点突出度 / 逻辑一致性）对简历做全面体检。输出 P0/P1/P2 分级问题清单，附带 STAR / CAR / PAR / 量化优先四种写作套路推荐，逐条确认后生成专业排版文件。

**适用场景**：简历初稿完成后第一轮打磨，或长期未更新简历的全面翻新。

### jd2resume · 匹配层
**向外对标，精准打击。**

输入岗位 JD，系统自动解析关键词、分析匹配度、标记已覆盖/偏差/缺失项。基于匹配结果调整叙述角度，自然融入 JD 关键词，最终输出 HTML / PDF / 长截图三种格式的投递文件。

**适用场景**：已锁定目标岗位，需要针对 JD 做定向优化。

### jd2resume-discuss · 诊断层
**深度拆解，找到真问题。**

结合简历与 JD 进行多视角对比分析，不是简单告诉你"哪里不对"，而是解释"为什么不对"以及"行业默认的写法是什么"。适合对某个岗位特别在意、想深入理解匹配差距的场景。

**适用场景**：高意向岗位，愿意花时间做深度准备。

### jd2resume-interview · 备战层
**模拟推演，提前布防。**

基于 JD 和简历内容，生成完整的面试准备方案：预测面试官可能问的问题、设计回答策略、标注避坑提示、输出准备清单。把面试从"临场发挥"变成"有备而战"。

**适用场景**：简历已投、面试在即，需要系统性备战。

### jd2resume-suite · 战略层
**一站式串联，效率优先。**

只需提供一次 JD 和简历，按顺序自动走完「深度讨论 → 简历优化 → 面试方案」全流程。适合时间紧张、希望一次搞定所有准备工作的场景。

**适用场景**：求职高峰期，批量处理多个岗位投递。

## 使用方式

```bash
# 1. 将本仓库添加为 Claude Code Skill
cd /path/to/claude-resume-os

# 2. 根据当前求职阶段选择对应 Skill 使用
#    - 简历初稿 → resume-polish
#    - 定向投递 → jd2resume
#    - 高意向岗 → jd2resume-discuss
#    - 面试在即 → jd2resume-interview
#    - 批量处理 → jd2resume-suite
```

每个 Skill 内部有完整的交互流程定义，按照提示逐步执行即可。

---

## 设计原则

1. **事实优先**：不编造经历，只调整叙述角度
2. **具体可执行**：每条建议精确到"改哪一句、怎么改"
3. **用户确认机制**：不一次性全改，逐条对比原写法 vs 建议写法，让用户选择
4. **多格式输出**：HTML（可编辑）、PDF（直接投递）、长截图（手机查看）
